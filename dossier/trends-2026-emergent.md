## 4. Метод

1. Тренд-источники открыты и процитированы по URL (раздел 1).
2. Проверка отсутствия в каталоге: точный поиск по name_en/name_ru всех 1045 позиций + 100 кандидатов.
3. Цели связей — только существующие позиции каталога (или принятые кандидаты v1.2 с номером V2).
4. Строка-отношение пишется по канону (предмет/механизм/назначение/границы), затем РЕЛОМАТ исполняет её как конечный автомат: SAME только при пересечении ролей; инструмент×метод → TOOL-OF; стандарт×практика → METHOD-OF; стандарт×принцип → INSTANCE; разновидность → IS-A; усиление → COMPLEMENTARY; иначе RELATED/NEW.
